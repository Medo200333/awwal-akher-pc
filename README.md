# أول وآخر

حضور وانصراف هيكفيجن: أول بصمة وآخر بصمة، ولوحة أجهزة فيها سحب واختبار ومزامنة.

## التشغيل

محتاج Node.js 22.

```bash
npm install
npm run dev
```

افتح العنوان اللي يظهر في التيرمنال.

## السحب

1. اكتب حساب موقع hik-connect.com وكلمة السر في الصفحة.
2. لو الموبايل مصري اكتبه `2010xxxxxxxx`.
3. اضغط سحب على الجهاز.
4. لو الجهاز له عنوان ظاهر، استخدم تبويب عنوان الجهاز.

متحطّش كلمة السر في أي ملف.
